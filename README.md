## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/niyazmehmed/python-openai-chatbot.git
cd python-openai-chatbot
```

### 2. Install the dependency

```bash
python -m pip install openai
```

### 3. Configure your API key

Set your `OPENAI_API_KEY` environment variable using a valid API key. Do not place secret keys directly in your source code or commit them to GitHub.

### 4. Run the Python file

```bash
python Practical_Open_AI.py
```

Some exercises may require you to configure the appropriate model and API parameters before running.
